h3. Simple explanation
* A technician brings IR photos in straight from a FLIR camera on a FLIR-SEP work order (Add IR Photos, FROM CAMERA).
* When a visual photo is linked to a pair the technician typed earlier, the picture does not show until the app is closed and reopened. The refresh button does not help.
* There is also one question about how photo editor markers are named on iOS compared with web, and one wording fix.
* The "visual name with no picture" problem that was first listed here has moved to ZP-5157. It comes from the stored data and also shows on web.

h3. 1. A visual linked from the camera does not show until the app is reopened
* A visual photo whose name matches a typed visual key was linked from Browse Camera. Seen twice on 2 Nov: FLIR7394 on the row FLIR7393 + FLIR7394, and FLIR7396 on FLIR7395 + FLIR7396.
* Web showed the picture straight away. On iOS the visual tile stayed empty, even after the refresh button.
* It showed only after closing and reopening the app (screenshot 6).
* Only the camera path: the same steps through Files (Browse & Select) show the picture straight away.
* *Re-tested 3 Nov 2026 on iOS 1.74 (same QA build): reproduced again.* Pair FLIR7411 + FLIR7412: Link at 12:18 IST, tile still empty after refresh at 12:19 and 12:21, picture shown after reopening the app at 12:25 (screenshot in the attached QA-03Nov-ZP-5156-repro-pack.zip).
* Expected: the picture shows right after the import, as it does for normal pairs and for the Files path.

!QA-02Nov-iOS-IRgap-6-visual-tile-needs-app-restart.png|width=480!
_Screenshot 6: top, after Link and refresh, the visual tile is empty. Bottom, after reopening the app, the visual shows._

h3. 2. Question: marker names in the photo editor are different on iOS and web
* Same photo (FOTRIC0383), same markers, same readings. Web shows the camera's names Bx2, Sp2, El1, Sp1, Sp3, Sp4.
* iOS shows numbers 1, 2, 3, 4, 5, 6. For example, web Sp1 78.8 is "4" on iOS (screenshot 5).
* The iOS FLIR editor also uses numbers, so this looks like the iOS editor's design.
* Question: should iOS and web use the same marker names (for example the camera's Sp1, Bx2)? If not, this part can be closed as by design.

!QA-02Nov-iOS-IRgap-5-marker-names-ios-vs-web.png|width=640!
_Screenshot 5: left iOS (markers 1 to 6), right web (Bx2, Sp2, El1, Sp1, Sp3, Sp4). Same photo, same values._

h3. 3. Small: the name field hint shows a FLIR name on FOTRIC work orders
* On the Edit IR Name sheet, when a name field is empty, the grey hint shows FLIR0041 and FLIR0041_visual, on FOTRIC-SEP and FOTRIC-IND work orders too.
* FOTRIC files are named like FOTRIC0384, so on FOTRIC work orders the hint should show a FOTRIC name, for example FOTRIC0041 and FOTRIC0041_visual. Low priority, wording only.
