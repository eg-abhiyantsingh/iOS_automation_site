h3. Part 1. QR code number beside the asset name in pickers
*Now:*
* Asset lists already have a QR Code column: the Assets page and the work order's Assets tab.
* The pickers show only the name and the class.
* Example: Work order › Actions › Add New Asset › Link Existing Assets.
** "QA-DEMO ZP-4874 SEP asset 27 Oct" has the QR code QA4956-6237.
** The picker shows only "QA-DEMO ZP-4874 SEP asset 27 Oct / Panelboard".
** The same picker lists two rows named "Capacitor 1", and nothing tells them apart.

*Expected:*
* Wherever an asset is picked, show its QR number in brackets after the name, for example *Main Breaker (90505)*.
* This covers these pickers:
** Link Existing Assets (work order);
** Link Existing Node (asset › OCP section);
** connection source and target;
** parent pickers.
* No brackets when the asset has no QR code.

h3. Part 2. Quick Add child names use the parent's initials
*Now:*
* Edit Asset › OCP › + › Create New Child opens "Quick Add Child Assets", which says "Names will be auto-generated".
* The names are the class name plus the next number: Circuit Breaker 1, Circuit Breaker 2, Circuit Breaker 3.

*Expected* (same rule as ZP-5168 part 4, so the three apps name children the same way):
* The suggested name uses the parent's initials as a prefix:
** parent "Main Distribution Panel" › MDP-1, MDP-2;
** parent "Motor Control Center" › MCC-1.
* The prefix can be changed before Add.
* A suggested name never repeats an existing name under the same parent; the next free number is used.

*To confirm with product:* should renaming the parent later rename its children? (Suggested: no.)
